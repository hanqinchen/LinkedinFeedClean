FeedFolders for LinkedIn Privacy Policy
Effective date: June 4, 2026

FeedFolders for LinkedIn is a browser extension that helps users organize LinkedIn people and company pages into topic folders.

Data the Extension Uses
FeedFolders reads LinkedIn page structure locally in the browser so it can detect profile links, company links, author names, and visible Follow buttons.

FeedFolders stores folder data selected or created by the user, including folder names, folder colors, LinkedIn profile or company paths, display names, optional LinkedIn identifiers, optional avatar image URLs, display settings, and exported or imported backup data.

How Data Is Stored
Folder data is stored in the user's browser using Chrome storage. The extension may also keep a local browser backup to help restore data after extension reloads or storage failures.

Exported backups are generated locally from the user's folder data.

Data Sharing and Transfer
FeedFolders does not sell user data.

FeedFolders does not use user data for personalized advertising, retargeting, or interest-based advertising.

FeedFolders does not send folder data or LinkedIn page data to the developer's servers.

FeedFolders does not allow humans to read user data, except if the user voluntarily provides data for support or where required by law.

Permissions
The extension requests access to LinkedIn pages so it can add folder controls, detect profile and company links, show folder tags, and help users navigate to folder-specific LinkedIn content results.

The extension uses Chrome storage to save folder data and settings in the user's browser.

The extension uses context menu and active tab functionality to support quick add workflows on LinkedIn pages.

Third Parties
FeedFolders is an independent browser extension and is not affiliated with, endorsed by, or sponsored by LinkedIn Corporation.

When the user opens LinkedIn pages, LinkedIn's own privacy practices apply to LinkedIn's website and services.

Changes
This policy may be updated when the extension's behavior changes. Any material changes will be reflected in the published privacy policy.
